- 难度定位：初中级
- 筛选说明：上一版题目偏向 LLM 推理服务、向量索引和生产级调度，难度偏高。本版改为国内 Agent 开发岗更常见的基础工程题，重点覆盖 Agent Loop、Function Calling、RAG、工具异常处理、记忆与评估。初中级题不可避免会和历史题的核心主题轻微重叠，但本版只保留面试中必须能讲清楚的基础问法。

## 1. 什么是 Agent？它通常由哪几部分组成？

- **分类**：Agent 基础
- **难度**：初级
- **考察要点**：LLM、工具、状态、循环、目标导向
- **参考答案**：
  - Agent 可以理解为围绕一个目标自主完成任务的程序。它不只是调用一次大模型，而是会根据当前状态决定下一步要不要思考、调用工具、读取结果或继续执行。
  - 常见组成包括：模型、Prompt、工具、状态记忆、执行循环和停止条件。
  - 初级面试中不需要把 Agent 说得很玄，重点是讲清楚：模型负责推理，工具负责连接外部能力，状态负责保存中间结果，循环负责多步执行。
  - 不是所有场景都需要 Agent。如果任务流程固定、规则明确，用普通工作流会更简单、稳定、可控。
- **通俗理解**：普通 LLM 调用像问一次问题；Agent 像让一个助手按目标分步骤办事，过程中可以查资料、调用系统、记录进度，并决定下一步。

## 2. 最小 Agent Loop 一般怎么跑？为什么需要停止条件？

- **分类**：Agent Loop
- **难度**：初级
- **考察要点**：observe、think、act、trace、max_steps
- **参考答案**：
  - 最小 Agent Loop 可以抽象为：观察当前输入和状态，思考下一步动作，执行动作，再把结果写回状态，然后进入下一轮。
  - 工程上通常会记录 trace，包括每一步做了什么、输入是什么、输出是什么、是否出错，方便排查问题。
  - 必须设置停止条件，例如最大步数、超时时间、成本预算、任务完成判断。否则模型可能因为判断不准或工具结果不完整而反复执行。
  - 初中级回答只要能说清楚“状态流转”和“终止条件”即可，不需要展开复杂多 Agent 调度。
- **通俗理解**：Agent Loop 像按清单办事：看现在有什么信息，决定下一步，执行后记录结果。如果没有截止条件，就可能一直纠结下去。

## 3. Function Calling 的完整流程是什么？

- **分类**：工具调用
- **难度**：初级
- **考察要点**：工具定义、参数生成、程序执行、结果回传
- **参考答案**：
  - 开发者先把可用工具告诉模型，包括工具名、用途描述和参数结构。
  - 模型根据用户问题判断是否需要工具，并生成结构化的工具调用请求，例如调用哪个函数、传哪些参数。
  - 程序侧不能只相信模型输出，必须解析并校验参数，再真正调用本地函数、HTTP 接口、数据库或业务系统。
  - 工具执行结果会作为消息回传给模型，模型再根据结果生成最终回答，或者继续决定是否调用其他工具。
- **通俗理解**：Function Calling 不是模型真的会执行代码，而是模型“开了一张调用单”，真正干活的是程序。

## 4. 设计一个工具接口时，为什么要写清楚参数和返回值？

- **分类**：工具设计
- **难度**：初中级
- **考察要点**：Schema、参数校验、错误兜底、可控性
- **参考答案**：
  - 工具描述越清楚，模型越容易判断什么时候该调用、该传什么参数。描述模糊会导致误调用、漏参数或参数类型错误。
  - 参数 Schema 应尽量明确字段名、类型、必填项和枚举值，程序侧还要做二次校验，不能把模型生成的参数直接交给真实系统。
  - 返回值要稳定，最好是结构化数据，方便模型理解和后续流程处理。
  - 对有副作用的工具，例如下单、删除、发消息，要有权限控制、幂等保护和人工确认，避免模型误操作。
- **通俗理解**：工具接口像给助手的表单。表单字段越明确，助手越不容易填错；涉及真实操作时，还要有人把关。
- **来源**：[cite:3](#source-3) [cite:4](#source-4)

## 5. RAG 的基础链路是什么？

- **分类**：RAG 基础
- **难度**：初级
- **考察要点**：文档入库、切分、Embedding、检索、生成
- **参考答案**：
  - RAG 通常分为两段：离线入库和在线问答。
  - 离线阶段会读取文档、清洗文本、切分 Chunk、生成 Embedding，并写入向量库或检索系统。
  - 在线阶段会把用户问题转成查询，检索相关片段，把片段和问题一起放进 Prompt，让模型基于资料回答。
  - RAG 的核心价值是让模型使用外部知识，减少只靠参数记忆回答导致的过时信息和无依据回答。
- **通俗理解**：RAG 像开卷考试。先把资料整理成索引，答题时先找相关资料，再根据资料组织答案。
- **来源**：[cite:5](#source-5) [cite:6](#source-6)

## 6. Chunk、Embedding、Vector Store 和 Retriever 分别做什么？

- **分类**：RAG 组件
- **难度**：初级
- **考察要点**：分块、向量化、存储、召回
- **参考答案**：
  - Chunk 是把长文档切成较小片段，方便检索和放入上下文。
  - Embedding 是把文本转成向量，让语义相近的内容在向量空间中更接近。
  - Vector Store 负责存储向量和元数据，并支持相似度查询。
  - Retriever 负责根据用户问题取回最相关的内容，它可以只用向量检索，也可以结合关键词检索、过滤条件或重排。
- **通俗理解**：Chunk 是资料卡片，Embedding 是给卡片做语义编码，Vector Store 是卡片柜，Retriever 是从柜子里找卡片的人。
- **来源**：[cite:5](#source-5) [cite:6](#source-6)

## 7. Agent 中的 Memory 一般存什么？初级项目先做哪种？

- **分类**：Memory
- **难度**：初中级
- **考察要点**：短期记忆、长期记忆、用户偏好、上下文控制
- **参考答案**：
  - 短期记忆通常保存当前会话的上下文、工具结果和中间状态，帮助 Agent 在一次任务中连续执行。
  - 长期记忆可以保存用户偏好、项目规则、历史成功经验等，但必须注意权限、时效和冲突更新。
  - 初级项目优先把短期状态和 trace 做清楚，不要一开始就把所有聊天记录都写进向量库。
  - 记忆不是越多越好。无关历史会污染上下文，增加成本，也可能让模型引用过期信息。
- **通俗理解**：短期记忆像这次办事桌面上的材料；长期记忆像用户档案。初学阶段先把桌面材料摆清楚，再考虑长期档案。
- **来源**：[cite:2](#source-2) [cite:7](#source-7)

## 8. 工具调用失败、超时或返回格式不对时，Agent 应该怎么处理？

- **分类**：异常处理
- **难度**：初中级
- **考察要点**：重试、降级、错误消息、状态记录
- **参考答案**：
  - 首先要区分错误类型，例如参数错误、网络超时、权限不足、业务系统报错、返回格式不符合预期。
  - 对瞬时错误可以有限重试，但要设置次数、超时和退避，不能无限重试。
  - 对参数错误或格式错误，应把可理解的错误信息写入状态，让模型修正参数或转为澄清问题。
  - 对关键业务操作失败，应明确告诉用户失败原因或给出降级方案，而不是假装已经完成。
- **通俗理解**：工具失败时，Agent 不能装作没事。它要知道失败在哪里，能修就修，不能修就说清楚。
- **来源**：[cite:3](#source-3) [cite:8](#source-8)

## 9. 如何初步评估一个 Agent 做得好不好？

- **分类**：Agent 评估
- **难度**：初中级
- **考察要点**：任务完成率、工具调用正确率、成本、人工评估
- **参考答案**：
  - 初级阶段可以先看任务完成率：用户目标有没有达成，答案是否基于正确资料，操作是否真的执行成功。
  - 工具型 Agent 要看工具调用正确率，包括是否选对工具、参数是否正确、失败后是否能恢复。
  - 还要看效率指标，例如平均执行步数、响应时间、Token 成本和人工介入次数。
  - 评估时最好准备固定测试集，覆盖正常问题、边界问题、工具失败和资料缺失，而不是只试几个成功案例。
- **通俗理解**：评价 Agent 不能只看回答像不像，要看任务有没有办成、有没有乱调用工具、失败时有没有兜住。
- **来源**：[cite:1](#source-1) [cite:9](#source-9)

## 10. 初中级面试中，LangChain、LangGraph 和 MCP 分别需要了解什么？

- **分类**：框架与生态
- **难度**：初中级
- **考察要点**：框架定位、状态图、工具协议、学习边界
- **参考答案**：
  - LangChain 可以理解为开发 LLM 应用和 Agent 的工具库，提供模型接入、Prompt、工具调用、RAG 等常用能力。
  - LangGraph 更强调有状态的流程控制，适合包含分支、循环、人工确认和可恢复执行的 Agent。
  - MCP 是连接模型应用和外部工具、资源的协议，目标是用统一方式暴露工具能力，而不是每个工具都写一套私有接入方式。
  - 初中级面试不需要背框架内部实现，重点是知道它们分别解决什么问题，以及什么时候不需要上复杂框架。
- **通俗理解**：LangChain 像常用开发工具箱，LangGraph 像能画流程和保存状态的执行图，MCP 像统一的工具接入插座。
- **来源**：[cite:2](#source-2) [cite:10](#source-10) [cite:11](#source-11)
