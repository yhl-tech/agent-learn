## 1. Agent 的长期记忆为什么不能只追加？用户纠正旧信息或要求忘记时应该怎么处理？

- **分类**：Memory 基础治理
- **难度**：初中级
- **考察要点**：记忆更新、时效性、冲突处理、过期与删除
- **参考答案**：
  - 长期记忆只追加不更新，会同时召回新旧住址、偏好或业务状态，使 Agent 根据过期信息回答甚至调用工具。写入前应判断新信息是新增、补充、重复还是对旧记忆的纠正。
  - 对“用户从北京搬到上海”这类状态变化，应让新值成为当前有效信息，并把旧值标记为已失效或历史记录；记忆应保存来源、更新时间、适用条件和有效状态，检索时先过滤失效内容，再计算相关性。
  - 临时信息可以设置 TTL，到期后不再参与默认召回；重复记忆可以合并，低价值记忆可以降权或归档。不能简单按创建时间删除所有旧记忆，因为长期偏好与临时安排的有效期不同。
  - 用户明确要求忘记某条信息，或信息被确认错误时，应执行可验证的删除，并同步清理相关摘要、缓存或派生资料。更新、过期和删除规则要用“旧信息不再被召回”等用例测试，不能只测试是否记得住。
- **通俗理解**：记忆库像通讯录，朋友搬家后不能只新增一个上海地址，却仍让旧的北京地址参与导航。系统要知道哪个信息当前有效、哪个只是历史；用户要求删除时，还要把相关副本一起清掉。
