# Agent 学习笔记

这个目录用于记录 Agent 开发线学习过程中的每日笔记、概念判断和项目复盘。

## 目录结构

```text
learning_notes/
├── README.md
├── daily/
│   └── 每日学习记录
└── templates/
    └── daily_note_template.md
```

## 记录原则

1. 每天只记录真正理解或实践过的内容。
2. 每篇笔记都要包含：概念、企业场景、当前项目映射、下一步动作。
3. 不复制长篇资料原文，只保留自己的判断和可执行结论。
4. 优先围绕 `页面需求分析 Agent` 项目积累。

## 当前主题

- Agent vs Workflow 的边界判断。
- 页面需求分析 Agent 的项目边界。
- 结构化输出与 Pydantic schema。
- 后续扩展：Agent Loop、工具设计、Context、Trace、Eval。
